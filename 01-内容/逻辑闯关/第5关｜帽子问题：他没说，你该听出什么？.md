# 第5关｜帽子问题：他没说，你该听出什么？

上一关讲的是"知识可以分层"。这一关把那个结构落到一个具体动作上：从别人没做到的事里，推出结论。

> 本关只需要知道：三个人依次被提问，每个人都能听见前面人的回答。不需要读过第 4 关。

---

## 规则设定

三个人 A、B、C，每人头上戴一顶帽子。

- 一共 5 顶帽子：3 顶黑，2 顶白。三人各戴一顶，剩下 2 顶收起来。
- 每个人能看见另外两人帽子的颜色，看不见自己的。
- 不能交流，不能照镜子。
- 依次提问：先问 A，再问 B，最后问 C。每个人都能听见前面的回答。

---

## 题一 · 第一声"不知道"

### 题目

问 A："你知道自己帽子的颜色吗？"

A 看了看 B 和 C，说："不知道。"

问：从这一句话，你能推出什么？

（30 秒。这题不难，但答案比你想的具体。）

### 答案

**B 和 C 当中，至少有一个是黑帽。**

为什么？把 A 能看到的两种极端情况摆出来：

- **如果 B、C 都是白帽**：白帽一共只有 2 顶，都在别人头上了，那 A 只能是黑帽。A 会立刻回答"知道，我是黑"。
- **如果 B、C 里至少有一个黑帽**：A 就没法确定自己是什么。他可能黑也可能白，看不出来。

A 说的是"不知道"，那就排除了第一种情况。

所以确定的是：B、C 至少一个黑。

注意这里推出了什么、没推出什么。你推不出 B 的颜色，也推不出 C 的颜色，更推不出 A 的。你只推出一条："B、C 全白"这个可能性，被 A 的回答划掉了。

一条回答，划掉一整类可能性。这就是全部收获。

## 题二 · 第二声"不知道"

### 题目

接着问 B："你知道自己帽子的颜色吗？"

B 也看了看，说："不知道。"

问：C 的帽子是什么颜色？

（这题需要把上一问的结论用起来。想 3 分钟。）

### 答案

**C 是黑帽。**

B 不是随便说"不知道"的。B 刚才听见了 A 的回答，所以 B 知道一件事：B 和 C 当中至少有一个黑帽。

现在 B 看着 A 和 C，做一次假设：

> "如果 C 是白帽呢？"

如果 C 真是白帽，那么"B、C 至少一个黑"这条就只剩一种可能——B 自己必须是黑帽。B 会立刻回答"知道，我是黑"。

但 B 说的是"不知道"。

所以"如果 C 是白帽"这个假设不成立。C 是黑帽。

整条链条是这样走的：

1. A 说不知道 → B、C 至少一个黑
2. B 知道了这件事，还说自己不知道
3. 如果 C 是白，B 就能确定自己是黑，就不会说不知道
4. B 说了不知道 → C 不是白 → C 是黑

最妙的地方在于：**C 从头到尾什么都没看见，也没被问到，却已经能确定自己的颜色了。** 他只需要听两句话。

而 A 和 B 呢？他们到最后仍然不知道自己的颜色。A 只知道"B、C 至少一个黑"，现在知道 C 是黑，这条信息对 A 自己的颜色毫无帮助。B 也一样。

三个人，两句话，只定出了一个人的颜色。这不完美，但这是确定的。

## 现实运用：反事实推理，现实里能不能用？

> 帽子问题：从"他说不知道"这一个动作里，推出一个确定结论。
> 现实中真的能这样读人吗？

能，但有个前提必须先说清楚：**现实中的沉默，原因太多了。**

没听懂、不在意、正在想、不方便说、在等你先说、纯粹走神——这些都会表现为"没有回答"。所以别把每一次沉默都当成证据。

能用的是这个思维动作：

**先问"他有没有条件知道"，再问"他知道了会不会说"。两个都是"是"，那他的沉默才算信息。**

三个具体场景：

- **面试时问"你了解我们这个岗位吗"**：对方答得含糊、绕开细节。不是他不想答，是他没准备。这个"答不出"比任何漂亮话都有信息量——它说明求职动机大概不在这。
- **谈判里你报完价，对方没有立刻反驳**：而是"嗯……我们再看一下别的"。如果报价离谱，人会本能地立刻反弹。没反弹，说明这个数字落在可接受区间里，只是他还想再压一点。
- **问一个"本该知道"的人细节，他答不上来**：可能他不在决策链上，也可能这个项目他没真正参与。但下结论前先自查一句：这个细节，是不是本来就不需要他知道？如果是，那这条推理作废。

第三条是这套方法最容易翻车的地方。反事实推理的杀伤力很大，所以用之前要先确认前提成立。

一句话总结：**他没做到的事，往往比他做到的事更能说明问题——前提是他本来做得到。**
