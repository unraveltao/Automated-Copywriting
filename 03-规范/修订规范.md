# 修订规范 v1（80 篇统一体检标准）

依据：`00｜项目规划与写作模板.md` 第二节「单篇结构模板 / 排版规范」、第三节「可跳读设计」、第五节「交付前自查清单」。

## 一、总原则

1. **最小必要改动。** 不改题目、答案、数字、招式名、叙事口吻、板块顺序。
2. **只修两类问题**：与模板硬性要求冲突的；逻辑不成立或不完整的。
3. 每篇改动后字数变化控制在 ±15% 以内。不许为了凑字数灌水。
4. 不许新增谜题（一关最多两题，季终关三问），不许删板块。

## 二、必改项

### 1. 可跳读行（模板第三节）

位置：H1 之后、第一个 `---` 之前，紧跟在开场 1–3 句后面。

格式（引用块，单独一行）：

```
> 本关只需要知道：<一句话，说清读这关需要的前置概念，≤40 字>
```

- 没有前置 → `> 本关不需要前置知识。`
- 季终关 → `> 本关是季终关，三问。前九关的招式都会用到，但每一问都能独立作答。`（可微调，但必须点明"能独立作答"）
- 已经有的（如第 5 关、第 20 关、第 40 关），保留原句，不要重复添加，措辞不顺才微调。
- 禁止写成"本关讲的是……"这种概述，必须是**前置知识**说明。

### 2. 加粗收敛（模板第二节「排版规范」）

配额：**强调型 ≤10 处，全篇加粗总数 ≤20 处**。第 1 关（结 16 / 强 3 / 共 19）是基准。

- **结构型**（行首标签式，如 `- **情况 1：你问到的是 A = T**`、`**假设 A = T（诚实）**`）：保留，但每个板块 ≤4 个。
- **强调型**：只保留三类——
  1. 招式名首次出现
  2. 每个答案的**第一句结论**
  3. 关键转折（"但/然而/其实"所在的短句）
- 其余一律去掉 `**`，**只删星号，不改文字**。整句加粗、整段加粗、重复强调、装饰性加粗全部拆掉。
- 特别注意：不要把穷举列表里的身份标签去掉——那是结构型，读者靠它定位。

### 3. 禁用词与符号（模板第二节）

| 类别 | 处理 |
|---|---|
| 禁用词：显然、易证、众所周知、不得不说、值得一提的是 | 改写或删除 |
| 符号 ∑ ∀ ∃ ∏ √ ≤ ≥ ≠ ∞ ≈ | 换中文：根号、大于等于、不等于、无限、约、乘 |
| emoji | 删除 |

### 4. 季终关补「现实运用」

适用：第 20、30、40、50、60、70、80 关（缺 `## 现实运用` 的）。

位置：放在「综合 / 本季最想说的一句话」之后、「本季招式总表」之前。

格式：

```
## 现实运用：<本季核心招式>，现实里怎么用？

> <把本季主张压成一句话，两行以内>
> 现实中能不能用这招？

<第一步：破除误用，1–2 句。>
<第二步：加粗一句可迁移的习惯。>

- <动作 1，明天就能做>
- <动作 2>
- <动作 3>
```

3 条动作必须具体到"动作"，不许写"保持批判性思维"。

## 三、逻辑体检项（逐条核对，有问题才动）

| # | 检查 | 不合格的典型 | 怎么改 |
|---|---|---|---|
| a | 答案是否穷举 | 只给"因为所以"的直觉解释；三种身份只走了两种 | 把每种情况补全，逐条走完 |
| b | 题二是否靠"加限制"升难度 | 加新人物、新道具，变成另一道题 | 改成限问几次、限几步、限信息 |
| c | 招式名是否解释"为什么成立" | 只写"所以这招叫 X" | 补一句机制解释 |
| d | 现实运用是否先破误用再给 3 条动作 | 停在"要独立思考" | 补破除段 + 3 条动作 |
| e | 回指旧关编号是否正确 | "第 12 关讲过平衡态"但平衡态在别关 | 对照模板第四节招式库改对 |
| f | 数字算得对不对 | 概率、比例、天数算错 | 重算，改对 |
| g | 同一关内是否自相矛盾 | 前文说 A，后文说非 A | 统一说法 |
| h | 是否只给结论没给推理 | 直接抛"答案是 3 次" | 补推理链 |

回指旧关的写法统一为：`（第 N 关：招式名）` 或正文一句 `第 N 关讲过 XX——<一句话解释>`。**不许只丢编号不解释。**

## 四、不许做的事

- 不许改文件名、不许改 H1 标题（标题由主控统一处理）。
- 不许动 `00｜项目规划与写作模板.md`。
- 不许引入公式，不许出现 ∑/∀/∃。
- 不许把"季终关"改成普通两题结构，反之亦然。
- 不许编造题目来源。

## 五、验收

改完跑：

```bash
cd 04-工具
python audit_articles.py <起> <止>
python audit_articles.py --合集 <合集名>          # 别的合集；不写就是 逻辑闯关
```

必须 0 硬伤（`!!`）。仅允许"偏短/偏长/钩子偏长"这类 `~` 提示。

`audit_articles.py` 的骨架判定按合集的 `形态` 走（见 `01-内容/<合集>/_合集.json`）：
`关卡制` 才认「第N关 / 每 10 关季终 / 缺题一缺题二」，`散篇`、`连载` 只查标题、
可跳读、现实运用、尾句、排版。所以本规范里的「第N关」条款只对关卡制合集生效。
