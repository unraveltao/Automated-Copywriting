# 04-工具 的依赖

#            不需要 pip install 任何东西。需要 Python 3.10+。

#   npm i playwright-core
#
#   如果本机已经有 Playwright，也可以用环境变量指过去，避免重复下载：
#   PLAYWRIGHT_CORE=/path/to/playwright-core
#
#   浏览器用系统安装的 Chrome（channel: 'chrome'），不额外下载 Chromium。
