# 逻辑闯关

一个谜题，换一个能带走的思维招式。

## 铁律（违反任何一条，这篇就不合格）

1. 读者读完必须能说出一个**招式名**（2–6 字），并知道什么时候用它。只记得"这题好妙"= 失败。
2. 不教知识，教招式。不是数学题集、不是脑筋急转弯、不是科普搬运、不是鸡汤。
3. 答案必须**穷举**：每种情况走一遍，不许用"因为所以"跳过。
4. 招式名必须解释**为什么成立**，不能只写"所以叫这个"。
5. 现实运用必须给 3 条明天就能做的动作，不许停在"要保持批判性思维"。（小红书文档版压到 2 条，见 03，这是唯一允许的减量。）

## 开工前（按顺序，别跳）

1. 项目里有 `00｜项目规划与写作模板.md` 就读第二节，有 `03-规范/修订规范.md` 就读它——它们是权威，本技能是它们的操作版。两者与本技能冲突时以它们为准；文件不在（换了电脑、只拿了这一个包）就以本技能的 `references/02-骨架与硬规则.md` 为准，不要停下来找。
2. 查 `references/01-百关总表.md`：这一关属哪一季、谜题、招式、落点、季内位置（轻 / 中 / 硬 / 综合）。想看这一关具体问了什么、答案口径是什么，读 `references/06-百关文本要点.md` 的对应条目。
3. 读 `references/05-语感样本.md`。不要只读规则，要读原文。
4. 写或重写 81–100 关时，先读 01 的「附一：81–100 每关写哪两题」。选题已定稿，不要自行换；招式名以正文为准（95–99 关在写作时已细化）。

## 写一关：七步

### 1 定关

确认四件事：季与主题、季内位置、招式（不能与已有招式重复）、现实落点。位置决定篇幅和难度——别把轻关写成硬关。

### 2 撞题检查

- 同一招式不写第二遍；同一道题不换包装再写（模板里两次换题都是这个原因）。
- 季内连续几关偏同一类（如图论），要错开切口：一个讲失效、一个讲成本、一个讲爆炸。
- 确实重复了：标"进阶关"，开头写明"这招第 12 关学过，这次加一个更狠的版本"。读者不反感复习，反感假装新东西。

### 3 定两题

- 题一入门，5 分钟内能想明白。
- 题二靠**加限制**升难度：限问几次、限几步、限信息。不是加人物、加道具。
- 季终关可写三问，但必须递进，且每问能独立作答。

### 4 写答案

先一句结论（加粗）→ 每种情况穷举 → 点招式并解释机制。数字自己算一遍，概率、比例、天数不许错。读者要的是"你怎么想出来的"，不是答案本身。

### 5 起招式名

2–6 个汉字，优先已有中文词；首次出现括注学名，之后不再注。新招式回填总表——那是这个项目唯一的累积资产。

### 6 现实运用

先破误用（谜题的假设在现实里哪里不成立）→ 一句可迁移的习惯（加粗）→ 3 条动作。动作要具体到"明天能做"，不是"保持独立思考"。

### 7 收尾与自检

1–2 个具体提问（读者能立刻回答）+ 固定尾句一字不差。然后跑 02 第十节清单；本机有 `04-工具/audit_articles.py` 就跑它，0 硬伤再交付。

## 硬规则速查

| 项 | 规则 |
|---|---|
| 文件名 | `第N关｜谜题名：钩子？.md`，与 H1 逐字一致 |
| 标题 | 必须是问句（含疑问词或以问号收尾），≤30 字，冒号后钩子 ≤26 字 |
| 开场 | ≤3 句，第一句进题 |
| 可跳读 | `> 本关只需要知道：…` ≤40 字，紧跟开场 |
| 人物 | 字母代号（A/B/C、T/F/R），不用小明小红 |
| 题二 | 加限制升难度 |
| 答案 | 结论先行 + 穷举 + 招式机制 |
| 招式 | 2–6 字，解释为什么成立 |
| 现实 | 破误用 + 3 条动作（小红书 2 条） |
| 结尾 | 1–2 个提问 + 固定尾句（小红书换成下期预告） |
| 篇幅 | 2000–2800 字（软线 1800–4500） |

## 排版

- 段落 ≤4 行。`---` 只在大板块之间。`>` 只用于核心提问和现实运用引子。
- 强调型加粗 ≤10（只留三类：招式名首次、每问第一句结论、关键转折）；全篇 ≤20。
- 不用 emoji；数字用阿拉伯数字；不出现公式和 ∑∀∃√≤≥≠∞≈（写中文）。
- 禁用词：显然、易证、众所周知、不得不说、值得一提的是。

## 小红书文档版（详版见 03）

800–1000 字，`108×192mm / 11pt / 行距 1.9`。结构：标题 → 一句话钩子 → 题目 → 答案（穷举合并成 2 条）→ 这招叫什么 → 现实运用（压到 2 条）→ 下期预告 → 固定尾句。

结尾用下期预告、不用提问，现实运用只留 2 条——这是平台差异（文档版没有评论区的即时互动），不是与本技能冲突。除这两处，其余硬规则一条不减。

## 知乎版（详版见 03）

标题 ≤16 字，砍掉钩子；回答体约 1500 字；3–5 个标签按"精准 / 流量 / 兜底"三层；挂到具体问题下，别选 #益智游戏。

## 封面（详版见 `references/04-封面与工具.md`）

白底黑字居中三行：关卡号（等线，暗红 `#A32D2D`）+ 谜题名（马善政毛笔，墨黑 `#1A1A1A`，按宽度缩放）+ 钩子（等线，灰 `#787878`）。公众号/知乎 1280×792，小红书 1080×1440。没有脚本时只给参数，别自己画图。

## 交付格式

默认给两件，用户只要一件就只给一件：

```
1. 母稿：Markdown 全文（可直接存成 第N关｜….md）
2. 小红书文档版：Markdown 全文（交给 md2docx 或平台）
3. 封面参数：三行文字 + 字号 / 颜色 / 画布
```

不要输出空的"待补充"章节，不要把模板里的占位符留在正文里。

## 常见漂移（交稿前对一遍）

- 加粗失控：用加粗代替断句（历史上第 68、69 关到了 76–89 处）。
- 漏掉「本关只需要知道」（历史上 30 篇缺失，可跳读设计就断了）。
- 季终关只写综合和总表，忘了现实运用。
- 答案只给结论，没有穷举。
- 标题写成陈述句或标题党。
- 现实运用停在"要独立思考"。
- 跨篇口径相反（第 78 与第 80 关对"缓冲"的说法曾经相反）。
- 回指旧关只丢编号不解释。

### 一、季与难度

一季 10 关，100 关 = 10 季。**只规划当前季**，下一季写完后按当时状态重排。

| 关序 | 定位 | 要求 |
|---|---|---|
| 1–3 | 轻关 | 3 分钟读完，题漂亮但不难，负责拉新 |
| 4–7 | 中关 | 需想 5–15 分钟，账号主体 |
| 8–9 | 硬关 | 允许烧脑，负责"这号有深度" |
| 10 | 综合关 | 串本季招式，难度中上，负责留存 |

# 附录：骨架与硬规则

## 骨架与硬规则

> 这是文章的施工图。每一节都对应一条可检查的规则，写完逐条对。

### 一、标题与文件名

```
第N关｜<谜题名>：<钩子问句？>.md
```

- 文件名与 H1 **逐字一致**，含全角标点。封面脚本从文件名读关卡数据，改标题必须同时改文件名与 H1。
- 钩子必须是**问句**：含疑问词（怎样 / 能不能 / 为什么 / 到底 / 多少 / 哪），或以问号收尾的反问。
- 标题总长 ≤30 字；冒号后的钩子 ≤26 字（超了手机端会截断）。
- 关卡号一律阿拉伯数字（第 10 关、第 100 关），不用中文数字。

| 好 | 坏 |
|---|---|
| 真假难辨时，怎样找到宝箱？ | 一道让 99% 的人崩溃的逻辑题（标题党，无信息） |
| 没有退路，反而更有底气？ | 你以为是运气，其实是铁律（陈述句，没有回答的冲动） |
| 每一组都赢，为什么合起来却输？ | 辛普森悖论讲解（名词标题，没有动作） |

**不要**把答案写进标题。

### 四、季终关（每季第 10 关）

允许破例的只有**题目结构**：可以写三问，对应本季三个招式，不必凑成题一/题二。

- 三问之间**必须有递进**，不能是三段互不相干的并列。
- 每一问都能独立作答（第三段之前说明这一点）。
- 结尾必须附**本季招式总表**（关 / 招式 / 一句话），可以再加一张"什么时候用哪一招"。
- 现实运用不能省：允许破例的是题目，不是价值落点。3 条动作照给。

季终关的骨架：

```
开场（点明"这一季讲的是 X" + "这一关不给你新题"）
可跳读行（点明季终、三问、可独立作答）
规则设定（一个真实场景，用一张表压住信息）

```

### 五、排版规范

- 段落不超过 4 行（手机一屏内）。
- 加粗分两类，**只对第一类计数**：
  - **强调型**（结论句、招式名、关键转折）：全篇 ≤10 处。
  - **结构型**（"情况一""假设 X 是…""列表引导词"）：不计入，但每个板块 ≤4 个。
- 全篇加粗总数 ≤20 处。基准：第 1 关 19 处（强 3 / 结 16），第 2 关 16 处。
- 强调型**只留三类**：招式名首次出现、每一问的第一句结论、关键转折（"但/然而/其实"所在的短句）。
- 其余星号一律去掉——**只删星号，不改文字**。整句加粗、整段加粗、重复强调、装饰性加粗，都是失控的开始。
- 硬线就是上面的 10 处。到 15 处以上，这篇基本已是在"用加粗代替断句"，读者会跳过所有加粗——两条线不冲突：10 是及格线，15 是确诊。
- `---` 只用于大板块之间。
- `>` 引用块只用于两处：核心提问、现实运用的引子。不要拿来做金句展示。
- 不用 emoji（小红书文档版同样不用）。
- 数字用阿拉伯数字。
- 数学符号克制：只允许 A/B/C、T/F/R、N 这类单字母，**禁止公式和 ∑/∀/∃**；根号、大于等于、不等于、无限、约，一律写中文。

### 六、语言

- 句子以 15–30 字为主，一段 2–4 行；结论单独成段。
- 术语第一次出现必须用大白话解释一遍，不许为了显得高深而堆词。
- 禁用词：显然、易证、众所周知、不得不说、值得一提的是。标题在研究某个词时（如第 95 关"什么都显然"），该词出现在标题中不算行文用词，但正文里仍不许用。
- 允许锋利短评（"力气花了，信息是零"）与自嘲（"作者懒，不定期更新哟"），不许说教。
- 数字必须具体：313 页、5 分钟、27 天、1.68 倍。一个能自己算出来的小数字，比十个商业案例更有说服力。

### 七、篇幅

- 目标 2000–2800 字（不含空白）。
- 体检软线：低于 1800 字标"偏短"，高于 4500 字标"偏长"。软提示可接受，但要能说出为什么。

### 八、可跳读设计（百关系列的地基）

- 每关第三段之前必须有 `> 本关只需要知道：…`，一句话说清前置概念。
- 没有前置就写 `> 本关不需要前置知识。`
- 季终关写：`> 本关是季终关，三问。前九关的招式都会用到，但每一问都能独立作答。`
- 回指旧招式必须带解释：`第 12 关讲过平衡态——不追求每步占便宜，只把"谁轮到谁输"的局面留给对方`。**不许只丢编号。**
- 任何一关都不能出现"必须补完前 N 关才能读"。

### 九、不许做的事

- 不许把答案写成"标准解法罗列"。读者要的是**你怎么想出来的**。
- 不许一篇塞 3 个以上谜题（两题是上限，季终三问）。
- 不许编造"这道题来自某位数学家"之类的来源。不确定就不写来源。
- 不许为凑字数灌水；改动旧稿时字数变化控制在 ±15%。
- 不许把季终关改成普通两题结构，反之亦然。

### 十、交付前自查（全过才算完）

- [ ] 标题是问句，含疑问词或以问号收尾，≤30 字
- [ ] 开场第一句就在讲题
- [ ] 有「本关只需要知道：…」
- [ ] 难度符合季内位置（轻关不烧脑，硬关不注水）
- [ ] 题一比题二简单，且难度差来自"加限制"
- [ ] 两个答案都穷举了每种身份 / 情况
- [ ] 招式有名字，并解释了"为什么成立"
- [ ] 现实运用先破误用，再给 3 条可执行动作
- [ ] 强调型加粗 ≤10，全篇 ≤20
- [ ] 无公式、无 ∑∀∃√≤≥≠∞≈、无 emoji、无 5 个禁用词
- [ ] 结尾 1–2 个具体提问 + 固定关注语

# 附录：三平台改写

## 三平台改写

> 同一个选题，三个平台是**三种写法**，不是一份稿子复制三遍。
> 顺序：先写公众号母稿（它最完整），再往下压成小红书文档版，最后改成知乎回答。

| 平台 | 形态 | 长度 | 产出 |
|---|---|---|---|
| 公众号 | 长文，Markdown | 2000–2800 字 | `第N关｜….md` + 封面 1280×792 |
| 小红书 | **文档**（docx/pdf） | 800–1000 字 | `06-存档/<合集>/文档版/第N关｜….docx` + 封面 1080×1440 |
| 知乎 | 回答体，挂到具体问题下；另建合集做入口 | 1500 字左右 | 直接用 `01-内容/<合集>/` 的母稿改 + 合集资料 |

路径都按合集走，`<合集>` 默认 `逻辑闯关`，其它合集加 `--合集 X`。封面在 `02-视觉/<合集>/`，文档版在 `06-存档/<合集>/文档版/`（发完即删）。

小红书是文档流，**不是图文卡片**。所以小红书版必须重写，不能把公众号长文直接转格式。

### 一、小红书文档版

#### 平台事实（写之前先对齐）

- 支持 doc / docx / pdf / ppt / pptx。
- 单次只能传 1 个文件，≤100MB。
- 上传后文件预览会自动加作者水印。
- 内容需符合平台规范（无站外导流、无极限词、不承诺功效）。

#### 版式（照做，不要自由发挥）

- **页面 108×192mm**（手机竖屏比例），正文 11pt，行距 1.9。
- 用 A4 的话，手机按宽度铺满时字会缩成蚂蚁。
- 标题层级只保留三级，不要套模板里的多层编号。

#### 字数与结构

800–1000 字，八个板块：

1. **标题**：`第N关｜谜题名：钩子？`（可略短，仍要问句）
2. **一句话钩子**：母稿开场压成 1–2 句，直接进题
3. **题目**：场景 + 限制 + 问题，控制在 150 字内
4. **答案**：先结论，再穷举——但**合并成两条**，不做四段展开
5. **这招叫什么**：招式名 + 一句"为什么成立"
6. **现实运用**：压到 **2 条**动作（母稿是 3 条）
7. **下期预告**：一句，点下一关的题材
8. **固定尾句**：公众号必留；小红书文档版可留，留就一字不差（不要改成"关注我"）

可跳读句保留，压进开头第一段（≤30 字）。

#### 结尾为什么是"下期预告"而不是提问

文档形式没有评论区的即时互动感，提问会显得空。预告才有"追更"的理由。

#### 生成

```bash
python 04-工具/mk_xhs_note.py 41 --docx   # 母稿 → 小红书 md → docx（草稿，800–1000 字）
python 04-工具/md2docx.py "06-存档/逻辑闯关/文档版/第N关｜谜题名.md" "06-存档/逻辑闯关/文档版/第N关｜谜题名.docx"
```

`md2docx.py` 零依赖（只用标准库），支持 `#/##/###`、`-`、`>`、表格、`**加粗**`；页面、字号、行距已写死在脚本里（108×192mm / 11pt / 1.9）。

#### 常见错误

- 直接把 2500 字母稿转成 docx——手机上 20 多屏，读完率极低。
- 用 A4。
- 四段穷举全留。
- 结尾留"你怎么看？"。
- 正文里放 `https://` 链接或二维码（判导流）。

### 二、知乎版

#### 标题：≤16 字，砍掉钩子

公众号标题在知乎会被截。只留"关卡号 + 谜题名 + 核心动作"：

| 公众号（22 字） | 知乎（16 字内） |
|---|---|
| 第1关｜守卫难题：真假难辨时，怎样找到宝箱？ | 第1关｜守卫难题：怎样找到宝箱？ |
| 第2关｜骑士与骗子岛：哪句话，全岛没人说得出？ | 第2关｜骑士与骗子岛：哪句话没人说得出？ |
| 第3关｜卡片翻面：翻哪两张，才能验证这条规则？ | 第3关｜卡片翻面：该翻哪两张？ |
| 第10关｜季终关：三份材料摆在面前，你先信哪个？ | 第10关｜季终：三份材料你先信哪个？ |

#### 正文：回答体，约 1500 字

- 开头 2 句就进题（"先给结论"），不要"谢邀"式铺垫。
- 题面压短；答案保留穷举，但可以比公众号少一层复述。
- 招式名与"为什么成立"必须留。
- 现实运用 2–3 条，比公众号更口语。
- 结尾不要公众号关注语，改成一句"这个系列我还写过 X"式的自然收束。

#### 标签：3–5 个，三层结构

| 层 | 数量 | 选什么 |
|---|---|---|
| 精准层 | 1–2 | 读者会主动订阅的话题（#逻辑学 #概率论 #统计学 #悖论） |
| 流量层 | 1–2 | 中等热度、内容相关（#逻辑思维 #批判性思维 #博弈论） |
| 兜底层 | 0–1 | 泛话题（#知识 #思维方法），别超过 1 个 |

超过 5 个会稀释。**别选 #益智游戏**：点进来的人期待玩一局，看到的却是两千字穷举，第三段就划走，完成率低反而拉低评分。

#### 增长线：回答，不是文章

文章靠标签，天花板低；回答挂在已有问题下，直接继承几年积累的关注。做法：文章照发当存档和合集入口，再把每篇改写成回答，挂到对应问题下。

| 关 | 可挂问题 |
|---|---|
| 1、2 | 有哪些有趣的逻辑推理题？/ 如何判断一个人是否在说谎？ |
| 3 | 什么是逆否命题？ |
| 4 | 有哪些细思极恐的逻辑题？/ 什么是公共知识？ |
| 6 | 三门问题的正确答案是什么？ |
| 7 | 为什么体检阳性别急着慌？/ 什么是贝叶斯定理？ |
| 8 | 生日悖论怎么解释？ |
| 10 | 如何提高逻辑思维能力？ |

#### 合集

合集名「逻辑闯关」，封面 3:4、≤5MB、黑白极简（留白七成以上，只用一个视觉元素）。简介三版任选，均 ≤100 字：

- **A（推荐）**：用逻辑谜题练判断力。从守卫难题到三门问题，每关只教一个能带走的思维招式：答案必须穷举，结论必须落到现实。适合想练脑子又不想啃教材的人。
- **B**：每关一道经典谜题，每关一个能带走的招式。不教知识，教招式——读完你能说出它的名字，也知道什么时候该用它。
- **C**：一个谜题，一个招式，十关一季。答案必须穷举，结论必须能用在现实里。这里不聊"逻辑思维很重要"，只给你具体的判断动作。

合集按关卡号挂全，不要只挂前几关——越完整越像"已经写成的体系"。

### 三、三平台对照

| 模块 | 公众号 | 小红书文档 | 知乎回答 |
|---|---|---|---|
| 标题 | 22–30 字，带钩子 | 同公众号，可略短 | ≤16 字，砍钩子 |
| 开场 | 1–3 句进题 | 压成 1–2 句 | 2 句给结论 |
| 可跳读句 | 必留（≤40 字） | 压进开头（≤30 字） | 可省 |
| 题目 | 完整场景 | 150 字内 | 短 |
| 答案 | 穷举全走一遍 | 合并成 2 条 | 穷举，少一层复述 |
| 招式 | 名字 + 为什么成立 | 同左 | 同左 |
| 现实运用 | 破误用 + 3 条 | 2 条 | 2–3 条，口语 |
| 结尾 | 1–2 个提问 + 关注语 | 下期预告 | 自然收束 |
| 封面 | 1280×792 | 1080×1440 | 合集 3:4 |

### 四、改写时不许做的事

- 不许新增母稿里没有的经历、数据、来源。
- 不许为了凑 800 字，把穷举删成"因为所以"。
- 不许把"破误用"那一段删掉——它是这个账号和普通科普的分界线。
- 不许把标题改成"99% 的人都答错"这类标题党。

## 封面与工具

> 封面风格定死，不要自由发挥：**白底、黑字、居中、不加任何图形**。
> 版式参数写死在这张表里，任何时候都能重出。

### 一、版式参数

| 元素 | 字体 | 公众号 / 知乎 | 小红书 | 颜色 |
|---|---|---|---|---|
| 关卡号 | 等线 Deng | 50px | 62px | 暗红 `#A32D2D` |
| 谜题名 | 马善政毛笔（Ma Shan Zheng） | 按宽度自适应 | 同左 | 墨黑 `#1A1A1A` |
| 钩子 | 等线 Deng | 34px | 38px | 灰 `#787878` |

- 画布：公众号/知乎 **1280×792**（左右留白 104）；小红书 **1080×1440**（3:4，左右留白 96）。内容整体垂直居中。
- 谜题名按宽度自适应：目标宽度 = 0.92 × 正文宽，上限 260px（小红书 300px），下限 120px。所以 3–7 个字的标题摆在一起宽度基本一致。
- 关卡号一律阿拉伯数字，字距 26%。多位数（10、100）必须连写成一个整体，否则会被拆成"第 1 0 关"。
- 钩子直接取文章标题冒号后那半句，一句话一行，不加句号。
- 三行版式：关卡号 → 谜题名 → 钩子，全部居中。

### 二、数据来源：文件名

封面脚本从文件名 `第N关｜谜题名：钩子.md` 读关卡数据。写完一关文章，封面自动就有，不用维护列表。

文件名不合模板时，**先改文件名**（用 `retitle.py` 同步 H1），别急着往脚本里塞特例。

### 三、命令（本机有 `04-工具/` 时）

路径一律按合集走：母稿在 `01-内容/<合集>/`，封面出到 `02-视觉/<合集>/{公众号封面,小红书封面}/`，过程产物出到 `06-存档/<合集>/{卡片,文档版}/`。`<合集>` 默认 `逻辑闯关`，其它合集加 `--合集 X`：

python mk_xhs_note.py 81 --docx     # 顺手转 docx

```

> 卡片与文档版属于**过程产物**，项目里不留存：默认写进 `06-存档/<合集>/`，发完就删，需要时一条命令重出。唯一长期保留的视觉资产是封面（`02-视觉/<合集>/`）。

两个体检的分工：`check_level.py` 管"合不合规"，`logic_check.py` 管"对不对"。逻辑检查能自动判的只有四项（回指编号、算式、招式重复、动作条数），穷举是否真穷举、前后是否矛盾、推理链是否完整，仍要人读 02 第十节。

固定工作流：写完一关 → 体检 → 出公众号封面 → 要发小红书时再出竖版封面和 docx。不再手工做图，也不再单独存旧版备份。

### 四、没有脚本时（上传到平台后只有文字）

只产出**封面参数**，让用户在设计工具里叠字：

```

第 2 行：地图四色       马善政毛笔，300px 上限按宽度缩放，墨黑 #1A1A1A，居中

### 五、体检脚本怎么读

- `!!` 硬伤，必须修：标题无问句、缺"本关只需要知道"、缺题一/题二、缺现实运用、缺固定尾句、强调型 >10、总加粗 >20、禁用词、数学符号、emoji。
- `~` 软提示，可接受：偏短（<1800 字）、偏长（>4500 字）、钩子偏长（>26 字）。
- 输出示例：`!! 第81关 2043字 结 8 强 4 缺现实运用`。

脚本按 `修订规范.md` 判定，改脚本前先读那份规范。

### 六、字体与版权

- 马善政毛笔楷书（Ma Shan Zheng），SIL OFL 开源，可商用；文件在 `04-工具/fonts/MaShanZheng-Regular.ttf`。
- 关卡号用等线（Deng），系统字体。
- 毛笔体没有粗体，加粗靠描边（54px 字号配 2px 描边），不要用字重。

### 七、小红书卡片版（可选，非主形态）

平台现在走文档流，卡片只作补充。5 张一套（1080×1440）：封面 → 题目 → 答案 → 为什么 → 招式，脚本 `make_xhs_cards.py`。

- **自动模式**：`python make_xhs_cards.py 41`，直接从 `01-内容/<合集>/` 的文章抽「规则设定 / 题一答案 / 题二答案 / 这招叫什么」，版式沿用封面那套，100 关都能一次跑完。装不下会自动缩字号（最低 0.85），再装不下才砍末段。
- **手写模式**：脚本里的 `MANUAL` 字典。第 3 关是精修稿（带牌面方块和毛笔大字），想精修哪关就把那关抄进去。
- 招式名以 `06-百关文本要点.md` 为准——81–100 关的母稿没有「这招叫什么」小节，只能从 06 取。

如果要做：一屏一个观点、不超过 6 行、对照关系用两行并排，不要把段落塞进卡片。

### 八、小红书文档版怎么自动压

# 附录：语感样本（原稿摘录）

## 语感样本（原稿摘录）

> 仿写时对齐语感与节奏，**不要整段照抄**。三段样本分别代表：最老的口吻（1）、修订后的成熟口吻（41）、季终关的收法（80）。

### 样本一 · 第 1 关（入门关，最老的口吻）

> 今天不聊别的，直接上题。两道经典"守卫谜题"：第一道入门，第二道封神。建议先自己想，再往下划看答案。
>
> 本关只需要知道：三个守卫里，一个永远说真、一个永远说假、一个随机。不需要读过前面任何一关。

题一的答案这样开头：

> 随便挑一个守卫（比如问 A），问他：
>
> "如果我问另一个守卫，哪扇门通向宝箱，他会指哪一扇？"
>
> 然后——**走他指的反方向**。

穷举完两种身份后，收在一句机制解释上：

> 你不需要判断谁可信，只需让"不可信"自己抵消掉。

现实运用先破误用：

> 谜题里的守卫遵守严格规则：诚实者永远说真话，撒谎者永远说假话，随机者随机回答。现实中的人并不是这样运作的。
>
> 所以，双重反问不是测谎器。现实中更值得借鉴的是谜题背后的习惯：**把结论拆成可以核验的问题。**

结尾：

> 你觉得哪一问最容易绕进去？如果要核实一个现实中的说法，你会先问什么？
>
> 关注「像玩游戏一样学」，练脑子不费劲。作者懒，不定期更新哟！

### 样本二 · 第 41 关（修订后的成熟口吻）

开场三句，先接上一季，再给反差：

> 第四季拆的是"话"。这一季拆"数"。
>
> 数据一般不说谎，但把数据摆在一起的方式，能说出任何结论。这一关的现象最邪门——它不是算错，是真的。
>
> 本关不需要前置知识。只要会看百分比。

答案不给"标准解法"，给**判据**：

> 先问：我是在做"选择"，还是在"描述"？
>
> - 做选择（因果）→ 必须控制混杂变量，看分层。
> - 做描述（现状）→ 看合计没问题，但别拿它当因果。

现实运用：先破一个误解，再给动作，再上三个场景：

> 先破除一个误解：不是所有"合计"都有问题。只有当两组的构成差异很大，而且那个构成本身影响结果时，合计才会骗人。
>
> 能用的是这个动作：**看到一个"总体"数字，先找它的分母是怎么构成的。**
>
> - 两个团队的人效：……先看构成。
> - 两家公司的转化率：……分母不一样，转化率不能直接比。
> - 自己的体检指标：……"高于平均"可能只是"比病人健康"。

一句收束 + 提问：

> 一句话总结：总体数字是混合物。比之前，先看它是由什么混成的。
>
> 留个思考题：你最近看过一个"我们比他们高 X%"的说法吗？那个数字的两边，构成一样吗？

### 样本三 · 第 80 关（季终关的收法）

开场先交代季，再交代"这关不给你新题"：

> 这一季九关，讲的都是"时间"。
>
> 这一关不给你新题。给你一个真实项目，用这一季的招式，从头排一遍。

三问之间用"但这里有个更大的机会"这类转折递进，不是并列。

综合段压成一张表 + 一句话：

> | 步骤 | 做什么 | 用哪招 |
> |---|---|---|
> | 1. 估时 | 查历史，乘系数 | 计划谬误（78） |
> | 2. 排序 | 找关键路径，能并行就并行 | 调度（73）/ 优先级（72） |
> | 3. 留量 | 排到 80%，缓冲不外露 | 排队论（74）/ 帕金森（79） |
> | 4. 定义 | 写清"什么算做完" | 帕金森（79） |
>
> 四步里，最容易漏的是第 4 步。

全季最重要的一句，单独成段、加粗、不解释：

> **时间不是一个"容器"，你往里装事。时间是一个"约束"，它决定了你能做到什么程度。**
>
> **所以排期的本质，不是"把事塞进时间"，是"决定哪些事不做"。**

季终结尾：思考题 + 下期预告 + 固定尾句。

> 留个思考题：你手上正在做的那个项目，如果按"历史系数 × 80% 负载"重算一遍，会变成多少天？那个数字，你敢报吗？
>
> 下一季换个维度：从"时间"转到"空间"。有些问题，换个画法就消失了……
>
> 关注「像玩游戏一样学」，练脑子不费劲。作者懒，不定期更新哟！

### 从样本里抽出的共性

1. 第一句就是结论或反差，不铺垫。
2. 数字具体到能自己算：93%、1.68 倍、27 天、80%。
3. 承认失败与代价（"力气花了，信息是零"），可信度来自不完美。
4. 答案与判断句前置，解释在后。
5. 现实运用先破误用，再给能明天就做的动作。
6. 结尾必有：一句能截图的话 + 一个把问题抛回读者的问句。
7. 段落极短，平均 1–3 行，段间空行；加粗只落在结论与转折上。

# 附录：百关文本要点（每关问什么、答成什么、招式叫什么）

## 百关文本要点（每关问什么、答成什么、招式叫什么）

> 用法：这是 01 总表的文字版。01 回答"第 N 关写什么"，本文件回答"第 N 关的题面、两问、答案主结论、招式机制、现实落点长什么样"。
> 写新关前先扫同类关卡，避免撞题；改旧关前先看这关的答案口径，别把原文结论改反。
> 数据源：`01-内容/逻辑闯关/` 目录里 100 篇成稿正文（2026-10-26 抽取，数字与结论逐条核过原文）。
> 招式名照抄正文与 01 总表。个别超过 6 字（如「不知道自己不知道」「只找支持自己的证据」）是原文如此，不要自行缩短。
> 每关 5 行：题一、题二（季终关换成三问）、答案、招式、现实。

### 第一季 · 真假之间（信息不可信时怎么办）

#### 第1关｜守卫难题
- 题一：两个守卫一真一假，只能问其中一人一句，怎么找到宝箱门？
- 题二：加入第三名随机者 R，最多只能问三个问题，还能找到宝箱门吗？
- 答案：问另一个守卫会指哪扇门，然后走反方向；三守卫先用嵌套问法锁定非随机者，再问门。
- 招式：双重否定——让假话在转述时自己抵消，不必判断谁在撒谎。
- 现实：看财政数据或比报价时，先把结论拆成来源、基准、成本收益等可核验的问题。

#### 第2关｜骑士与骗子岛
- 题一：A 说「我是骗子」，他是骑士还是骗子？
- 题二：A 说 B 是骗子、B 说 A 和 C 属于同一类，能确定谁的身份？
- 答案：题一的场景在岛上不可能发生；题二中 C 一定是骗子，A、B 各有两种可能。
- 招式：分类讨论——把可能全列出来，逐个看能不能成立，不成立的划掉。
- 现实：听到「最后一套了」或内部消息时，先看说话人站在哪、说错要付什么代价。

#### 第3关｜卡片翻面
- 题一：四张卡 A、D、3、6，规则是元音背面为偶数，翻哪几张能验证？
- 题二：再补一句「辅音背面为奇数」后，同样的四张卡要翻哪几张？
- 答案：题一翻 A 和 3；题二四张全翻，两条单向规则合起来就是当且仅当。
- 招式：逆否命题——把「如果 P 则 Q」改写成「如果不是 Q，就不是 P」再查。
- 现实：验证一个说法时，先找它的逆否和反例，不要只数支持它的例子。

#### 第4关｜蓝眼睛岛民
- 题一：岛上有 1 个蓝眼睛、199 个棕眼睛，旅行者说完那句话后，当晚会发生什么？
- 题二：真实情况是 100 个蓝眼睛，第几晚有人离开，走的是谁？
- 答案：题一蓝眼睛当晚就离开；题二第 100 晚 100 个蓝眼睛一起离开。
- 招式：公共知识——当众说一句，补上「人人知道人人知道」那一层。
- 现实：项目要延期时，先在会上公开说出来，让所有人都知道别人也知道了。

#### 第5关｜帽子问题
- 题一：3 顶黑帽、2 顶白帽共五顶；问 A 是否知道自己颜色，A 说不知道，能推出什么？
- 题二：接着问 B，B 也说不知道，C 的帽子是什么颜色？
- 答案：题一 B 和 C 里至少一个黑帽；题二 C 是黑帽，A 和 B 仍不知道自己的颜色。
- 招式：反事实推理——他有条件知道却没说，这个「没说」本身就是信息。
- 现实：面试或谈判遇到对方含糊其辞时，先确认他本来知不知道、知道了会不会说。

#### 第6关｜三门问题
- 题一：选了 1 号门后主持打开 3 号羊门，该不该换成 2 号，换的胜率是多少？
- 题二：主持人不知道车在哪，随手开门恰好是羊，换不换还有区别吗？
- 答案：题一换，换是三分之二、不换三分之一；题二换不换各一半，差别在信息怎么产生。
- 招式：信息更新——新信息能不能改变概率，要看它是怎么产生的。
- 现实：体检或听人说方案不行时，先问这条信息是怎么产生的、谁付了成本。

#### 第7关｜体检假阳性
- 题一：患病率 1%、敏感度 99%、假阳性率 1%，无症状体检阳性，实际患病概率多少？
- 题二：有症状者患病率 20%，同样的检测同样阳性，患病概率变成多少？
- 答案：题一约 50%，真阳性 99 人对假阳性 99 人；题二约 96%，差别在检测前的基率。
- 招式：基率——检测结果要乘以做检测前的概率，才是答案。
- 现实：看到「识别率 99%」时，先问这东西本来有多常见，再算假阳性。

#### 第8关｜生日悖论
- 题一：房间里有 23 个人，至少两人生日相同的概率是多少？
- 题二：改成「有人和你同一天生日」且概率过半，需要多少人？
- 答案：题一约 50.7%；题二需 253 个别人加你共 254 人，和 23 人差十一倍。
- 招式：配对思维——概率按两两配对数算，不按人头算。
- 现实：遇到「太巧了」的事时，先算一共有多少种巧的可能，再决定要不要惊讶。

#### 第9关｜双信封悖论
- 题一：一个信封里的钱是另一个的两倍，不打开时该不该换？
- 题二：打开看到 100 元，按另一个 50 或 200 各一半的算法，错在哪？
- 答案：题一换不换完全一样；题二「各一半」是凭空假设，放钱规则未知就没有答案。
- 招式：对称性——没有信息区分两个信封时，两者的价值必然相等。
- 现实：有人说换方案期望更高时，先问那个概率是谁估的、怎么来的。

#### 第10关｜季终关·三份材料
- 题一：三份招聘材料（简历、背景调查、面试），你先信哪一个？
- 三问：简历那句该查什么；停顿两秒能推出什么；答错基础题后不合格概率多少
- 答案：查他负责过却负增长的项目；停顿只推出对方不愿正面评价；答错后不合格概率 80%。
- 招式：三行表——逆否查逻辑、反事实查来源、基率查权重，三行都过才改判断。
- 现实：刷到「不合格率 30%」这类消息时，先花三十秒按三行表定位它属于哪类问题。

### 第二季 · 有限步必胜（策略与边界）

#### 第11关｜十二球称重
- 题一：8 个球中有 1 个偏重，天平最多称 2 次，怎么找出它？
- 题二：12 个球不知偏重偏轻，称 3 次找出它并判断轻重，怎么称？
- 答案：可以；3 次称重最多区分 27 种情况，12 个球的 24 种装得下。
- 招式：信息量下界——每次试探最多能问出几种结果，决定你最少要试几次。
- 现实：排查故障时，先算每个检查动作能排除多少种可能，再决定第一个动作。

#### 第12关｜取石子
- 题一：20 颗石子，每次取 1 到 3 颗，取到最后一颗者赢，先手还是后手赢？
- 题二：改成两堆各 5 颗，每次从任意一堆取任意颗，取到最后者赢，谁赢？
- 答案：后手赢；20 是 4 的倍数，两堆相等也是必败位置；对策是取 4 减 k 颗、保持两堆相等。
- 招式：平衡态——不追求每步占便宜，只把谁轮到谁输的局面留给对方。
- 现实：在价格战或加班内卷里，先判断这是不是谁轮到谁输的平衡态，再决定改规则还是退出。

#### 第13关｜分蛋糕
- 题一：两人分一块蛋糕，都想多拿，没有裁判也没有秤，怎么分才都不觉得亏？
- 题二：蛋糕上多一颗你爱吃、对方无所谓的草莓，还是你切他选，你能拿到草莓吗？
- 答案：一人切、另一人先选；切的人按自己的估值切成两份，自己都认为相等。
- 招式：机制设计——不改变人，只改规则，让自私的人不得不做出公平选择。
- 现实：分家产或分任务时，先别急着找裁判，改成一个人列两份、另一个人先选。

#### 第14关｜井字棋
- 题一：两人都走最优、一步不错，井字棋先手赢、后手赢，还是平局？
- 题二：第一步有 9 个格子可下，真需要研究 9 种开局吗？本质上一共有几种？
- 答案：平局；开局实质上只有 3 种：角、边、中心，其余 6 种是旋转翻转后的重复。
- 招式：对称归类——先问这些看起来不同的选项里，有多少个只是同一事物的不同外观。
- 现实：手上同时有三个 offer 时，先按本质差别去重，看哪几个只是换了名字。

#### 第15关｜囚徒困境
- 题一：A 和 B 分开审讯不能沟通，各自只求自己判得最少，两人会怎么选？
- 题二：进去之前两人约好都沉默、扛过去，这个约定有用吗？
- 答案：两人都坦白，各判 5 年；约定没用，收益结构没变，背叛始终更优。
- 招式：纳什均衡——没人能靠单方面改变选择变好的状态，未必对所有人最好。
- 现实：发现「我也没办法、大家都这样」时，先画收益表，看是不是每个人单独改变都吃亏。

#### 第16关｜海盗分金
- 题一：只剩 D 和 E 两人、由 D 提案，至少一半同意才通过，D 会怎么分？
- 题二：回到 A 到 E 五人、A 先提案，A 怎么分才能通过，自己拿多少？
- 答案：两人时 D 拿 100、E 拿 0；五人时 A 拿 98，给 C 和 E 各 1 枚。
- 招式：逆向归纳——先解最后一步，再往前推一步，一直推回现在。
- 现实：谈薪资或分股权前，先算这一轮谈崩后下一步会怎样、对方那时能拿多少。

#### 第17关｜赢家诅咒
- 题一：10 个买家各自独立估价、出价最高者得，谁中标，他赚钱了吗？
- 题二：只有你一个人真懂行、估价很准，赢家诅咒还成立吗？该出价多少？
- 答案：最高估价必高于平均值也就是真实价值，中标者多半亏；懂行能减弱但没消除。
- 招式：赢家诅咒——大家都不确定真实价值时，赢常因为最乐观，而乐观要付代价。
- 现实：抢人或抢房出价前，先把估价往下调一点，抢的人越多就调得越狠。

#### 第18关｜胆小鬼博弈
- 题一：两人都绝对理性、都不想撞车也不想丢面子，最后谁会先躲？
- 题二：光靠表情凶狠没用，有什么办法能让对方确定你真的不会躲？
- 答案：没有唯一答案，有两个均衡；自断退路，把「躲」删掉，对方只能躲。
- 招式：可信威胁——自断退路，让对方确定你不会退，从而逼他退。
- 现实：谈判放话前，先做一个不可撤销的动作，让对方看得见你已经没有别的选择。

#### 第19关｜重复博弈
- 题一：要反复玩很多轮，每轮前都不知是不是最后一轮，第一轮该合作还是背叛？
- 题二：你第一轮合作、第二轮被背叛，之后该一直合作、永久拉黑还是对等报复？
- 答案：第一轮合作；选对等报复，即第一轮合作、之后照抄对方上一轮的做法。
- 招式：以牙还牙——第一轮合作，之后照抄对方上一轮；被背叛就还击，回头就恢复。
- 现实：长期关系里第一次先给善意，被占便宜就当场还击，对方回头立刻接住。

#### 第20关｜季终关·一场你必胜的赌局
- 题一：朋友说「规则你定，但我有权不玩」，你要设计一个他愿意上桌、你赢面大的局。
- 三问：石子放多少颗先手必胜；数量由他定怎么翻盘；连玩 10 轮每轮都赢好吗
- 答案：不是 4 的倍数先手必胜；改成取到最后者输可翻盘；连赢他会退出，要让他还有机会。
- 招式：平衡态——先算清谁轮到谁输，再决定自己站在局面的哪一边。
- 现实：接新项目或谈条件前，先列三行：数量谁定、规则谁定、我能不能不玩。

### 第三季 · 不可能的游戏（证明"做不到"）

#### 第21关｜七桥问题
- 题一：正方形四条边，笔不离纸、每边只画一次，能否一笔画完？
- 题二：正方形再加两条对角线画成 X，还能一笔画完吗？
- 答案：不能；四个顶点各连 3 条线，共 4 个奇点，一笔画最多容忍 2 个。
- 招式：抽象成图——把走桥的具体问题变成点和线的结构，问题就变可算了。
- 现实：任务互相卡着排不出期时，先画成点和连线，看有没有互为前置的死循环。

#### 第22关｜十五数码
- 题一：3×3 八数码底行是 8、7、空格，只差把 8 和 7 换位，能拼回去吗？
- 题二：换成 4×4 十五数码、只把 14 和 15 对调，还能拼回去吗？
- 答案：都不能；八数码比逆序数奇偶，十五数码还要加空格行号，初始与目标对不上。
- 招式：不变量——找一个怎么折腾都不变的量，比较起点和终点。
- 现实：团队反复出同样问题时，先找出换了人换了流程后一直没变的激励结构。

#### 第23关｜骨牌覆盖
- 题一：8×8 棋盘剪掉对角两格，31 张 1×2 骨牌能否正好铺满？
- 题二：改剪任意两个同色格子，还能铺满吗？
- 答案：都不能；剪掉两黑后黑 30 白 32，每张骨牌必占一黑一白，凑不出 31 比 31。
- 招式：染色法——黑白相间染色，骨牌必盖一黑一白，数量一对不上就铺不满。
- 现实：招人配项目时，先数开发与测试各几个，数量对不上加开发没用，得补缺口。

#### 第24关｜倒水问题
- 题一：3 升杯和 5 升杯没有刻度，怎么量出正好 4 升？
- 题二：换成 4 升杯和 6 升杯，还能量出 3 升吗？
- 答案：能量出 4 升，六步；4 和 6 的公约数是 2，只能凑出 0、2、4、6，量不出 3 升。
- 招式：公约数——两个容量的最大公约数，卡死了你能量出的每一个量。
- 现实：目标总差一点时，先算现有最小单位，目标不是它的整数倍就换工具。

#### 第25关｜汉诺塔
- 题一：三个盘子从 A 挪到 C，每次一个、大盘不能压小盘，最少几步？
- 题二：传说里 64 个金盘子，最少要挪多少步？
- 答案：7 步；64 个要 2 的 64 次方减 1 步，每秒一步也要约 5849 亿年。
- 招式：递推与下界——拆成同样的小问题加一步，既算出步数也证没有更快。
- 现实：估算审批流程或组织成本时，先按每加一层就翻倍算，别按加法估。

#### 第26关｜抽屉原理
- 题一：房间里坐着 13 个人，能否保证至少两人同一个月出生？
- 题二：红蓝黑三色袜子蒙眼摸、不放回，最少摸几只才保证 4 只同色？
- 答案：13 人必有两同月；10 只，最倒霉红蓝黑各 3 只后再摸一只。
- 招式：鸽巢原理——数量超过类别数，重复必然发生，不是概率。
- 现实：看到同类问题重复太多次，先看是不是可选项只有那么几类。

#### 第27关｜六人聚会
- 题一：6 个人任意认识或不认识，能否保证必有 3 人两两认识或 3 人两两不认识？
- 题二：5 个人还成立吗？这题要构造反例。
- 答案：6 人一定成立；5 人不行，坐成一圈只认识左右两人即可，6 是能保证的最小数。
- 招式：任取一个——先固定一个样本，把它和其余的按关系分堆，问题降一维。
- 现实：面对人太多事太杂的局面，先挑一个人，捋清他跟所有人的关系。

#### 第28关｜反证法
- 题一：证明根号 2 不是有理数，即不能写成两个整数相除。
- 题二：证明质数有无穷多个。
- 答案：两者都证得出来；判据是假设反面一路推下去必撞矛盾。
- 招式：反证法——假设结论不成立，一路推到矛盾，就等于证明了它。
- 现实：听到很有道理的说法，先假设它对，往下推三步看会不会自己塌。

#### 第29关｜先手不会输
- 题一：存不存在两个无理数 a、b，使 a 的 b 次方是有理数？
- 题二：象棋红先，能不能证明红方不会输？
- 答案：都存在，但指不出是哪个：分两种情况各给一对；红方偷黑方策略，只证不输。
- 招式：构造与存在——证明不可能没有，和把东西造出来给你，是两件事。
- 现实：听到一句「一定有」，先追问第一步是什么；指不出就只是个情绪。

#### 第30关｜季终关·你以为是运气
- 题一：5×8 巧克力共 40 格，每次掰一块成两块，掰成单格最少几次？
- 三问：掰巧克力几次；5 个整数里 3 个之和被 3 整除？；7 人各握 3 次？
- 答案：39 次，怎么掰都一样；5 个整数必有 3 个之和被 3 整除；7 人各握 3 次不可能，总次数 21 是奇数。
- 招式：不变量——先找那个动手前就定死、怎么动都不变的量。
- 现实：挑一件反复出问题的事，先写下这三个月里唯一没变的那一项。

### 第四季 · 语言的陷阱（问题出在问题上）

#### 第31关｜说谎者悖论
- 题一：纸上只写一句话「这句话是假的」，它是真是假？
- 题二：换成三句自指：本句有六个字、七个字、不是六个字，还能判吗？
- 答案：它既不是真的也不是假的，不承载真假；自指否定自己的真假就无解，否定外部属性可判。
- 招式：自指——一句话谈论自己时，先看它是描述属性还是否定真假。
- 现实：听到一条管所有人的制度或承诺，先问它管不管制定者。

#### 第32关｜理发师悖论
- 题一：理发师只给不自己刮胡子的人刮，他该不该给自己刮？
- 题二：把规矩改成除他之外的所有人，矛盾就解决了吗？
- 答案：两种假设都矛盾，这个理发师不存在；根源在「所有」这个词的范围。
- 招式：边界——听到所有、任何、一律，先问包不包括说这话的人。
- 现实：看到全员适用的制度，先把定制度的人代进去看还成立吗。

#### 第33关｜忒修斯之船
- 题一：船板一年换一块、几百年全换过，它还是原来那条船吗？
- 题二：旧木板被原样拼成另一条船，两条同时存在，哪条才是原来的？
- 答案：两种说法都站得住，因为一个按材质、一个按连续；该先问按什么算。
- 招式：定义先行——争不出结果时别加论据，先问说的是不是同一个东西。
- 现实：争论到第三轮，先问双方说的那个词具体指什么。

#### 第34关｜火鸡问题
- 题一：火鸡见了一千天早上九点有食物就推出明天也有，错在哪？
- 题二：若归纳无法证明，还能不能用，用的话要加哪两个条件？
- 答案：归纳只支撑到目前为止；要能用，得说清规律靠什么成立、什么能让它不成立。
- 招式：归纳的局限——样本越多越确信时，先问样本里是否缺了会改变一切的那天。
- 现实：听到「一直这样、从没出过事」，先问这期间有没有能推翻它的条件。

#### 第35关｜伽利略悖论
- 题一：平方数只是自然数的一部分，两者哪个更多？
- 题二：换成一条一厘米线段与一个一米见方的正方形，哪个点更多？
- 答案：都一样多；能一一配上就没有大小之分，对不上才有，包含关系不算数。
- 招式：一一对应——比大小别数个数，看能不能一个个配上。
- 现实：比较两个数或两个团队前，先问它们是不是在同一套单位上。

#### 第36关｜预设
- 题一：家里人问你「今天为什么又迟到」，这句话毛病在哪？
- 题二：换成戒烟、降价多少、支持谁三种问法，各藏什么预设、怎么答？
- 答案：毛病是把没确认的事塞进提问前提；破法是先纠正前提，再回答问题。
- 招式：预设——一句话要成立必须先成立的那件事，先听再判自己认不认。
- 现实：面试谈判前先停半秒，问自己这一答等于承认了什么。

#### 第37关｜偷换概念
- 题一：甲说自由很重要，乙拿闯红灯反问，问题出在哪一步？
- 题二：若没人故意换，老板说的效率和员工说的效率差在哪？
- 答案：同一个词前后指的不是同一件事；能用同一句话解释就是没换，不能就是换了。
- 招式：概念漂移——圈出反复出现的词，问它指什么，再比两次答案一样吗。
- 现实：争论卡住时，挑出现最多的词，问你说的这个词具体指什么。

#### 第38关｜循环论证
- 题一：书里第一章说本书可信，能否证明这本书可信？
- 题二：换成产品好与用户多互相撑，问题在哪；循环和正反馈怎么分？
- 答案：前提必须独立于结论；遮住结论前提站不住就是循环，当解释可成立、当证明必失效。
- 招式：论证结构——把结论遮住，看前提还能不能自己站着。
- 现实：准备被说服时，把对方的「因为」单独拎出来，问不知道结论时它说明什么。

#### 第39关｜稻草人
- 题一：从「适当减少加班」到「让大家都别干活」，中间发生了什么？
- 题二：加上识别应对，再问如果对方不是故意的，还算不算稻草人？
- 答案：被打倒的版本对方没说过，就是稻草人；应对是拿回原话重放，别为假版本辩护。
- 招式：稻草人——对方复述你的观点时，先看那个版本你认不认。
- 现实：情绪上来前，把对方原话复述一遍，问「你说的是这个意思吗」。

#### 第40关｜季终关·一段争吵
- 题一：这段群里吵远程办公的对话，有几次反驳其实没打到人？
- 三问：谁被反驳了；哪句在兜圈子；为什么吵不出结论？
- 答案：反驳至少三次没打到人，假理由分循环、归纳越界、预设，行不行和效率都没定义。
- 招式：拆三层——先看谁被反驳，再看哪句兜圈子，最后看哪个词没定义。
- 现实：吵到第三轮先停下论据，把对方的话复述一遍，问「是这个意思吗」。

### 第五季 · 数字会骗人（统计防身术）

#### 第41关｜辛普森悖论
- 题一：两种手术各治 350 人，分组看和合计看，哪种方法更好？
- 题二：同一批数字怎能处处 A 赢、总体 B 赢？问题出在哪个环节？
- 答案：分组看 A 全赢，合计看 B 赢；做选择看分层，做描述看合计。
- 招式：分层与合并——看到总体更高，先问两组构成是否一样。
- 现实：看到总体数字，先查它的分母由什么人构成，再决定能不能比。

#### 第42关｜幸存者偏差
- 题一：返航飞机机翼弹孔最多，该加固哪里？
- 题二：怎么找到那些被击落、没能返航的飞机？
- 答案：该加固弹孔最少的引擎、油箱、驾驶舱；中弹的都没回来。
- 招式：看不见的样本——手上的数据被筛选过，筛选规则就是结论来源。
- 现实：听到成功故事，先问做同样的事、失败了的人有多少。

#### 第43关｜冰淇淋与溺水
- 题一：冰淇淋销量越高溺水越多，是冰淇淋导致的吗？
- 题二：喝咖啡的人死亡率更低，混杂变量可能是什么？
- 答案：不会，天热同时推高两者；咖啡例还可能是生病让人戒了咖啡。
- 招式：混杂变量——两件事一起动，先找共同原因，再问是否反向。
- 现实：想说「所以我该做 X」之前，先问有没有 Y 同时导致这两件事。

#### 第44关｜平均工资
- 题一：老板涨薪从 5 万到 6 万、员工不变，平均涨了百分之几？
- 题二：平均值不可靠，该看哪个数才知道普通人拿多少？
- 答案：平均从 9500 涨到 10500 即 10.5%，员工仍 5000；该看中位数。
- 招式：分布——看到平均值，先问背后是尖峰还是长尾。
- 现实：听到平均薪资，先问有多少人在这个数以下、中位数多少。

#### 第45关｜赌徒谬误
- 题一：轮盘连开 10 把红，第 11 把该押红还是押黑？
- 题二：轮盘、抽牌、抛硬币、投篮，哪些系统有记忆？
- 答案：一样大都是 50%；四种里只有抽牌有记忆。
- 招式：独立事件——上次结果没改变条件，这次就还是五五开。
- 现实：冒出「该轮到我了」，先问上一轮结果是否改变了这一轮条件。

#### 第46关｜回归均值
- 题一：学生考 50 被批评后考 68，批评真的有用吗？
- 题二：怎么区分真效果和回归均值？原文要三个办法。
- 答案：不成立，两人平时都 70 分，只是回到均值；要有对照。
- 招式：回归均值——极端之后会回落，是规律不是功劳。
- 现实：归因之前，先问这批人是不是按最极端挑出来的。

#### 第47关｜抽样偏差
- 题一：240 万人的调查，怎么会输给盖洛普的 5 万人？
- 题二：盖洛普 5 万人更准，关键差别在哪个环节？
- 答案：240 万样本来自电话簿和车主，偏富裕；5 万人按人口结构配额。
- 招式：样本代表性——样本量解决不了找错人，要看结构对不对。
- 现实：听到 N 人调研，先问这 N 人怎么找到、谁不会出现。

#### 第48关｜图表陷阱
- 题一：100 万到 105 万的数据，哪张图在骗人？
- 题二：除截断纵轴外，常见图表手法还有哪些？
- 答案：两张都没造假，但柱状图纵轴从 95 起就是欺骗。
- 招式：坐标轴与基线——看图先看轴：起点、单位和时间窗口。
- 现实：看到增长图，先看纵轴从几开始，再看时间从哪天算。

#### 第49关｜大数定律
- 题一：抛得越多，正反面的绝对差距会缩小吗？
- 题二：抛 100 次出 70 次正面，要回 50% 需连抛多少反面？
- 答案：不会，差距按抛掷次数的平方根扩大；一个反面都不用。
- 招式：长期与短期——比例会稳定，绝对差距反而会扩大。
- 现实：看到比例波动，先问分母有多大；小样本的单月数字是噪音。

#### 第50关｜季终关·一份漂亮的报告
- 题一：一份报告七条结论，分别藏了哪七个坑？
- 三问：哪些数字什么也没说；那张图在骗什么；哪句是因果错觉
- 答案：七条都不假，只是没说全；每题先查分母、纵轴和样本边界。
- 招式：三句话——先查分母、纵轴、样本边界，能挡掉八成。
- 现实：拿到报告，先翻样本说明：多少人、怎么选、谁没算进去。

### 第六季 · 决策的暗面（决策论）

#### 第51关｜沉没成本
- 题一：花 80 元买票，开场 30 分钟发现难看，该走还是坐满 90 分钟？
- 题二：道理这么简单，为什么现实中几乎所有人都做不到？
- 答案：该走。80 元已花掉，走不走都拿不回；只看接下来 90 分钟怎么用最值。
- 招式：已付出的不算——问如果今天从零开始，我还会选它吗，答不会就停。
- 现实：纠结要不要继续时，先把已投入的从账本划掉，只算往后哪个更好。

#### 第52关｜机会成本
- 题一：免费咖啡值 30 元、要排队两小时，这杯咖啡的成本是多少？
- 题二：读研两年学费共 10 万、年薪 15 万，读研的成本是多少？
- 答案：不是 0 元，是两小时；读研真成本 40 万，含放弃的两年 30 万收入。
- 招式：你放弃了什么——把「付出了什么」换成「我因此没能做什么」。
- 现实：遇到免费或低风险的选择，先问这些时间本来能用在哪儿。

#### 第53关｜圣彼得堡悖论
- 题一：掷硬币到出反面，奖金 2 元起逐次翻倍，期望值是多少？
- 题二：数学没错，为什么期望值无限的结论不能用？要答两个层面。
- 答案：期望值无穷大，但由连续 99 万多次正面的极小概率撑起，现实中没人开得起。
- 招式：期望值失效——追问它是被大多数情况撑起，还是被几乎不可能的那次撑起。
- 现实：听到高期望值项目，先砍掉最好的 1%，看它还剩下多少。

#### 第54关｜一百万和一千万
- 题一：月薪从 5000 涨到 10000，幸福感会跟着翻倍吗？
- 题二：用对数感受重算圣彼得堡游戏，它相当于稳稳拿到多少钱？
- 答案：不会翻倍，感受按比例不按差额；这游戏约等于稳稳拿到 4 元。
- 招式：钱不等于价值——别比金额，比这笔钱能改变什么。
- 现实：两个 offer 比价时，先问哪个能改变我现在的处境。

#### 第55关｜决策树
- 题一：30 岁年薪 25 万想辞职，把两条路画成树，写概率、结果、代价。
- 题二：算辞职期望值；再把失败从归零改成退回后，结论会反吗？
- 答案：算得 16 万，不如不辞；改写成退回得 28 万；结论全压在猜的 40% 上。
- 招式：把选择画出来——展开分支、失败写退回哪儿、找出一变就翻的数字。
- 现实：选项多又反复想的决定，拿纸横画，每支写概率、结果、代价。

#### 第56关｜最大最小准则
- 题一：A 最好赚 100 万最坏亏 10 万，B 是 1000 万和 500 万，选 B 吗？
- 题二：什么情况下该用这个不管概率、只看最坏结果的准则？
- 答案：看亏不亏得起：最坏结果不可逆就用最大最小，可逆才看期望值。
- 招式：最坏情况优先——先写每个选项的最坏结果，再问它可不可逆。
- 现实：做大决定前，先问如果它彻底失败，我还能回到今天吗。

#### 第57关｜两个箱子
- 题一：A 箱红蓝各 50，B 箱比例未知，摸到红赢 100 元，选哪个？
- 题二：概率已知和概率未知，做决定时该用同一套方法吗？
- 答案：多数人两问都选 A，其实选的是「知道概率」；风险用算，不确定性用设计。
- 招式：已知未知 vs 未知未知——问概率是算出来还是编出来的，算的才用期望值。
- 现实：写计划前，先给每条假设分类：是有数据的，还是我们在猜的。

#### 第58关｜遍历性
- 题一：100 元玩 10 次，50% 变 1.5 倍、50% 变 0.6 倍，最后约剩多少？
- 题二：平均收益真是百分之五，为什么实际会亏？两种平均差在哪？
- 答案：按加法算 163 元，按乘法约剩 59 元；涨跌不对称，乘法过程要用几何平均。
- 招式：平均对个体无效——先问失败一次会不会出局，会出局平均就失效。
- 现实：采用长期看赚的策略前，先问中间会不会有一次让我出局。

#### 第59关｜帕斯卡赌注
- 题一：无限收益乘极小概率能压过有限损失，帕斯卡的推理成立吗？
- 题二：这论证哪里不能用在现实？又要哪三个条件才值得押？
- 答案：形式上成立，但前提有洞；只有成本一次性、上行真实、无互斥选项才值得押。
- 招式：极小概率极大收益——查成本是一次还是一直，上行是真的还是听说的。
- 现实：听到「万一呢」，先算这个成本会重复几次，再决定押不押。

#### 第60关｜季终关·两个 offer
- 题一：30 岁工作 7 年，A 年薪 35 万，B 是 28 万加期权，怎么选？
- 三问：A 的失败到底是什么；B 的期望值是多少；「安全」这词错在哪
- 答案：A 不是安全，是拿上行换掉下行；纠结的根源不是信息不够，是没定清优化什么。
- 招式：五层决策阶梯——先判断在算数、猜概率还是保命，再做那一层的事。
- 现实：卡住时先问我在算数、猜概率还是保命，只做那一层该做的动作。

### 第七季 · 系统与涌现（复杂系统）

#### 第61关｜正负反馈
- 题一：空调与麦克风同样输出回到输入，为什么一个稳定、一个尖叫？
- 题二：一个团队加两个人反而更忙，这是正反馈还是负反馈，会在哪里停？
- 答案：区别在反馈方向：负反馈抵消偏离所以稳定，正反馈放大偏离所以发散且不会自己停。
- 招式：反馈回路——找圈、判方向、找刹车，切断放大偏离的那一环。
- 现实：看到一个越来越糟的现象，先画成圈，再找能切断的那一环。

#### 第62关｜公地悲剧
- 题一：10 户牧民共用的草场，从自己利益出发该不该多养一头？
- 题二：有没有办法让这 10 户既保住草地，又不靠自觉？
- 答案：多养一头稳赚 1000 元、成本为 0，人人如此草场退化到 60 头，每户从 1 万降到 6000。
- 招式：共同资源——问好处和代价是不是落在不同人身上，收益私有就会过度使用。
- 现实：看到大家都在用、没人负责的资源，先问谁在承担代价。

#### 第63关｜路径依赖
- 题一：诞生于 1870 年代的 QWERTY 布局，是打字最快的布局吗？
- 题二：有没有三个信号，能让人认出这是路径依赖？
- 答案：它不是为效率设计，是为不卡杆；能长期存在不一定因为好，而是换掉成本太高。
- 招式：历史锁死——问这件事是更好，还是更早；答不出来就是路径依赖。
- 现实：看到一条一直都是这样的规矩，先问如果今天从零开始还会不会这么定。

#### 第64关｜局部最优
- 题一：只能往更高处走，站在 200 米处海拔 135，能走到 210 吗？
- 题二：有什么办法能从 135 走到 210？答案给了三个办法。
- 答案：走不到 210，两边都更低只能停在 135；先下降、从别处重启或换尺子才能到 210。
- 招式：爬山困境——问我是在爬得更高，还是在爬对的山。
- 现实：听到「我们一直在进步」这句话，先追问进步的是哪个指标。

#### 第65关｜网络效应
- 题一：用户从 10 人涨到 100 人，这个网络的价值涨了几倍？
- 题二：记账 App、通讯软件、打车软件、单机解谜游戏，哪些有网络效应？
- 答案：涨到约 110 倍；只有通讯软件和打车软件有网络效应，记账 App 和单机游戏没有。
- 招式：人多就值钱——问价值来自自己，还是来自别人也在。
- 现实：听到「我们有 100 万用户」，先问这 100 万用户之间有没有连接。

#### 第66关｜生命游戏
- 题一：三条规则下，中间三个活细胞的图案第 1 步、第 2 步变成什么样？
- 题二：换一个初始图案，这三条规则还能长出什么？
- 答案：第 1 步变竖的三个、第 2 步变回横的三个，是周期 2 振荡；还能长出滑翔机等结构。
- 招式：涌现——问结果是设计出来的还是长出来的，改结果要改规则。
- 现实：看到要求很多次也不变的行为，先找是哪条规则在让它重复。

#### 第67关｜蝴蝶效应
- 题一：洛伦兹把 0.506127 抄成 0.506，为什么两次模拟结果完全不同？
- 题二：一只蝴蝶在巴西扇翅膀引起美国飓风，这个说法哪里错了？
- 答案：错在把敏感依赖说成因果放大；它讲的是预测不可能，不是小事能变成大事。
- 招式：敏感依赖——问这个系统的误差会放大还是会收敛；放大只能准备。
- 现实：听一个长期预测之前，先问这个系统的误差会不会放大。

#### 第68关｜十个人的公共池
- 题一：10 人各持 100 元投入公共池翻倍平分，该投 100 元还是 0 元？
- 题二：有没有办法让 10 个人都投 100，又不靠觉悟？
- 答案：该投 0 元；都投 0 是纳什均衡总财富 1000 元，都投 100 才是 2000 元。
- 招式：集体行动——问在这件事里不做是不是比做更划算，是就改结构。
- 现实：看到对大家好却没人做的事，先问做的人会比别人多得到什么。

#### 第69关｜布雷斯悖论
- 题一：4000 辆车走对称的两条路，平衡状态下每辆车要走多久？
- 题二：修一条 A 到 B、用时 0 分钟的新路后，每辆车要走多久？
- 答案：65 分钟；修路后变 80 分钟、慢了 15 分钟，拆掉新路才回到 65 分钟。
- 招式：加路更堵——问这个增加有没有让每个人多承担自己的成本。
- 现实：在加人、加流程、加功能之前，先问加了之后大家会怎么用。

#### 第70关｜季终关·你身边那个停不下来的圈
- 题一：砍测试赶上线、两周后救火的研发团队，这个圈有哪几个变量？
- 三问：圈由哪些变量连成；为何两三年没人指出；三个方案里杠杆点在哪
- 答案：四变量一个正反馈圈不会自己停；延迟两周切断因果；最有效是统计救火时间每周公开。
- 招式：杠杆点——改数字不如改规则和改信息流，让看见后果的人自己改。
- 现实：想改一件说了很久没改的事，先画圈量延迟，再把隐性成本记成数字发给做决定的人。

### 第八季 · 时间与顺序（时序逻辑）

#### 第71关｜先发与后发
- 题一：甲先发投 1000 万教育市场，乙等两年跟进，按期望值谁更划算？
- 题二：把市场成功率从 50% 改成 30%，谁更划算？
- 答案：50% 时甲 1000 万胜过乙 750 万；30% 时反过来，乙 450 万胜甲 200 万。
- 招式：时机优势——先发那笔投入会变成我的资产，还是大家的公开信息。
- 现实：要不要第一个做时，先问这钱买到的是别人拿不走的资产，还是免费公开的结论。

#### 第72关｜优先级
- 题一：客户投诉今天不处理损失 5 万，产品基础能力一年损失 100 万，先做哪个？
- 题二：为什么代价增长慢、上限高的重要事总被推到明天？
- 答案：优先级看拖一天更贵；重要事缺「有人在等」，只能靠配额而非排序。
- 招式：优先级——别问哪个更重要，问哪个拖一天更贵。
- 现实：每周把做的事分成「有人催」和「没人催」两栏，看比例，再硬留 10% 给没人催的。

#### 第73关｜先做快的
- 题一：4 件事 2、4、6、8 分钟，先快和先慢的平均等待各是多少？
- 题二：为什么差这么多，现实中又为什么没人这么做？
- 答案：先快平均等 5 分钟，先慢 10 分钟；差的是一件事的时间被后面所有人承担。
- 招式：调度——先做快的，不是因为快，是让更多人早点完成。
- 现实：每天早上先花 15 分钟，把 5 分钟内能做完的事全清掉。

#### 第74关｜排队论
- 题一：负载 50%、80%、90% 时，一个请求平均各要等多久？
- 题二：为什么接近满载等待会爆炸，实际又该怎么做？
- 答案：分别等 6、24、54 分钟；过 80% 后每加一点负载代价翻倍，余量买的是抗波动。
- 招式：拥堵的数学——这个系统的负载，超过 80% 了吗。
- 现实：看到利用率 95% 别当好消息，先问剩下的 5% 用来吸收什么。

#### 第75关｜复利
- 题一：0.1 毫米的纸对折 42 次有多厚？
- 题二：每天进步 1%，一年 365 天后是多少倍？
- 答案：约 44 万公里，超过 38.4 万公里的地月距离；每天 1% 一年是 37.8 倍。
- 招式：指数直觉——别问涨了多少，问多久翻一倍。
- 现实：判断一件事值不值得坚持，先算它多久翻一倍，再查成果能否成为下次起点。

#### 第76关｜折现
- 题一：按 5% 年化，明年的 100 万相当于今天多少钱？
- 题二：折现率该由什么决定，短视是否一定是缺点？
- 答案：今天值 95.2 万，30 年后的 100 万只值 23.1 万；高折现率可能是低确定性的理性选择。
- 招式：未来的钱不值钱——把未来收益换算成今天的价值，再和今天的投入比。
- 现实：听到未来能赚多少，先问按多少折现，再和今天的投入比。

#### 第77关｜明天再说
- 题一：今天 100 元和明天 110 元、一年后 100 元和一年零一天 110 元，各选哪个？
- 题二：这对拖延意味着什么，又该怎么破？
- 答案：多数人第一组选 A、第二组选 D，自相矛盾；要改价格不改心态。
- 招式：延迟满足——不想做是它真不值得，还是现在被大脑放大了。
- 现实：该做没做的事，先问有没有把代价或收益挪到现在，再把选项拿走。

#### 第78关｜计划谬误
- 题一：1994 年研究里，学生论文实际完成时间落在哪个位置？
- 题二：为什么总低估，以及知道了也改不掉该怎么修正？
- 答案：实际平均 56 天，晚于 99% 把握的 49 天；改用外部视角查历史，缓冲不公开。
- 招式：总是低估时间——别问这次要多久，问这类事以前用了多久。
- 现实：做计划前先找三个同类项目的实际耗时，乘上自己的历史倍数。

#### 第79关｜帕金森定律
- 题一：老太太寄一张明信片，一整天没别的事会花多久？
- 题二：截止日期到底是什么，又该怎么设期限？
- 答案：花一整天；期限不是催你，是定义做到什么程度可以停。
- 招式：工作填满时间——这件事做完的标准是什么，答不出来时间就是标准。
- 现实：开始一件事前，先写下做到什么程度就停，再按结果倒推时间。

#### 第80关｜季终关·一个项目
- 题一：4 人团队估 27 天上线，这个数字的问题在哪？
- 三问：27 天可信吗；45 天怎么排；余量留多少
- 答案：按历史倍数 1.68 应是 45 天；关键路径 27 天，压非关键路径不省时；排到 80% 即 32 天，8 天缓冲不外露。
- 招式：排期四步法——估时靠历史，排序看关键路径，留量留 20%，写清什么算做完。
- 现实：报工期前先写一行「这次不做什么」，并翻最近 3 个同类项目算出自己的倍数。

### 第九季 · 空间与结构（几何与拓扑）

#### 第81关｜地图四色
- 题一：只用 6 种颜色，能不能保证任何一张地图都涂得开？
- 题二：颜色砍到 4 支，要造非用 4 色不可的地图，并说明 5 块两两相邻画不出来。
- 答案：6 色够用；4 块两两相邻的地图存在，三色无解；5 块两两相邻要 10 条线，平面上最多 9 条。
- 招式：分类的完备性——先数一共几类，再数最坏情况占掉几类，多出一类就有空位。
- 现实：列完清单后回头问，如果漏了一条它会落在哪一类；空的那类就是漏的那类。

#### 第82关｜正多面体
- 题一：只用一种正多边形，能拼出几种每面一样、每角一样的立体？
- 题二：每个顶点恰好 3 个面，是一个正五边形加两个正六边形，求两种面各几个。
- 答案：只有五种，四面体、立方体、八面体、十二面体、二十面体；足球是 12 个五边形、20 个六边形。
- 招式：约束交集——先把违反就不成立的条件当筛子，一条条筛，剩下的自己塌下来。
- 现实：动手做方案前，先列违反了就做不成的硬条件，用它们砍一遍再谈好坏。

#### 第83关｜莫比乌斯带
- 题一：三条纸带三种粘法，每条各有几个面、几条边？
- 题二：只准剪一刀：沿正中线剪得几个环，沿三分之一处剪又得几个？
- 答案：直接粘 2 面 2 边，翻半圈 1 面 1 边，翻一整圈 2 面 2 边；正中剪得 1 环，三分之一处剪得 2 环，两环相套。
- 招式：单侧曲面——别问有几层，问沿它走一圈能不能换到另一侧。
- 现实：看到两个对立的名字，先找一条从这头走到那头的路，看是不是同一面。

#### 第84关｜咖啡杯与甜甜圈
- 题一：只准捏、拉、压，带把咖啡杯能不能变成一只甜甜圈？
- 题二：只准用套绳和沿线剪开两个动作，怎么证明球面和甜甜圈不是同一个？
- 答案：能，两者都是 1 个洞；球面 0 个洞、甜甜圈 1 个洞，套绳与剪开给出的数一致。
- 招式：拓扑等价——不比形状，比不撕不粘之下必须一起保留的性质，也就是洞数。
- 现实：比较两个东西之前，先找出各自那个洞：外壳全换掉后还必须留下什么。

#### 第85关｜最短路径
- 题一：每步只挑本路口最短的一段，从家到公司共几分钟？最少几分钟？
- 题二：每次挑累计最短的点定稿并更新邻居，什么条件下必给出最短？
- 答案：按规则走 14 分钟，最少 7 分钟；条件是边不为负、整体最优能由局部最优拼成。
- 招式：贪心的边界——每步只挑当下最好；后面的账不因选择改变才必对，否则必错。
- 现实：做眼前最省的选择前，先问这一步省下的会不会让后面变贵。

#### 第86关｜最小生成树
- 题一：每次挑最便宜且不成圈的路，六座城十五条候选，总造价多少？
- 题二：不许枚举，只准换一次边，为什么造价 4 的 A-B 必在某个最优方案里？
- 答案：总造价 33，选 A-B、B-C、D-E、E-F、C-D；依据是割性质，最便宜的跨堆边必可入最优解。
- 招式：最省的连接——按价钱从小到大连，成圈就跳过，连到点数减一条为止。
- 现实：先问这件事的约束是不是一棵树，再从最便宜的开始连，成圈就跳过。

#### 第87关｜装箱问题
- 题一：十件货装进三个一样的箱子，一共有多少种装法？
- 题二：加容量 10，六件货重 6、5、3、2、2、2，先装大的用几个箱、最少几个？
- 答案：9330 种；先装大的要用 3 个箱子，最少只要 2 个，唯一分法是 6 和两个 2 一堆。
- 招式：组合爆炸——每多一件就乘三个岔，岔口是乘上去的不是加上去的。
- 现实：先数物件规模，二十件以上就把目标从最优改成够用，先定一条够用线。

#### 第88关｜旅行商问题
- 题一：八个城市从 A 出发的候选路线共几条？最短多长？
- 题二：加到 20 个城市、只给十分钟且不许全比一遍，能交出什么？
- 答案：2520 条，最短 52；20 城给出一上界一下界，277 与 405，最优必夹在中间。
- 招式：近似与下界——下界取任何解都逃不掉的地板，上界取真做出来的一条解。
- 现实：给够用方案配一条谁也逃不掉的地板，把上下两数写下来看还剩多少空间。

#### 第89关｜对称性破缺
- 题一：圆桌上两人轮流放一元硬币，放不下的输，先手有没有必胜法？
- 题二：切两刀分三块给三人、顺序抽签决定，规则对称结果能对称吗？
- 答案：有，先手放正中心，之后放在对手关于圆心的对称点；三块不一般大时，谁拿大的由抽签顺序定。
- 招式：对称性破缺——规则对称只管没人被条文特别对待，执行要排先后，对称会被消耗掉。
- 现实：看到对所有人都一样的规则，先去找它没管的输入：谁先、谁在哪、谁已有什么。

#### 第90关｜季终关·一张地图
- 题一：镇政府 P 加七个村 A 到 G、十条路，哪些该画成点、哪些该画成线？
- 三问：先做点线抽象；再数连通、度数与环；最后翻成一句最脆弱的地方
- 答案：8 个点、10 条线；连通，度数从 P 的 2 到 G 的 1，共 3 个环；最脆弱是 G 村。
- 招式：把地图变成图——只准写点和线，丢得越干净，图越好算。
- 现实：把最乱那件事写成点和线，圈出只连一条线的点，那就是单点故障清单。

### 第十季 · 元认知（怎么想自己怎么想）

#### 第91关｜达克效应
- 题一：最差组实际第 12 百分位、自评第 62，最好组 86 对 68，哪一行才是达克效应？
- 题二：招一个自称精通数据报表的人，只准问一个问题，问什么？
- 答案：最差组高估 50 个百分点，不是自评最高；问「难在哪、上次错在哪」，看尺子有无。
- 招式：不知道自己不知道——判断对错用的正是做对所需的知识，答案与尺子都缺。
- 现实：准备说「这个我会」时，先写一行：这件事做好的标准是什么。

#### 第92关｜确认偏误
- 题一：看到 2、4、6 符合规则，你报哪三组数，凭什么说猜对了？
- 题二：只准报一组，五个候选中报前须填两个空：符合放弃什么、不符合放弃什么。
- 答案：报 2、4、7，两种答案都能改主意；只找支持证据，认真却不有效。
- 招式：只找支持自己的证据——人主动找支持自己的证据，把同一测试做十遍。
- 现实：开会问意见时，把「大家还有什么意见」换成「最可能死在哪一步」。

#### 第93关｜锚定效应
- 题一：转盘停在 10 与 65，两组估中位数 25 与 45，这 20 个百分点说明什么？
- 题二：中介说同户型成交 620 万，你原打算出 500 万，只准做一件事让它失效。
- 答案：无关数字会把整组估计推走；写三个独立数，锚就从起点降为一个参照。
- 招式：第一个数字——锚只需在知识给不出答案处替你做主，调到合理即停。
- 现实：谈价前先在纸上写下自己的数和它的来由，谈判时只看纸。

#### 第94关｜框架效应
- 题一：600 人患病，A 是 200 人确定获救，C 是 400 人确定死亡，是一件事吗？
- 题二：手术五年存活率九成，数字一个不许改，只说一句让听众同时看到两种说法。
- 答案：A 与 C、B 与 D 各是一件事；说救人多求稳，说死人多赌一把。
- 招式：说法改变选择——换掉的是参照点，零点一换，得与失互换。
- 现实：看到「九成存活」这类话，自己补一句：每一百人里有十个不在。

#### 第95关｜后见之明
- 题一：上世纪七十年代对 2000 年的六条预测，成了几条？
- 题二：三句事后话，只准问一个问题，怎么分出真预见与事后补？
- 答案：只成了视频通话一条；判据是当时有没有留下痕迹，不是现在感觉多强。
- 招式：事后都清楚——记忆每次重拼，已知结局会抹掉当时的不确定。
- 现实：复盘前先读当时写下、带日期的判断，再看结果，顺序不能反。

#### 第96关｜可得性启发
- 题一：英文里以 K 开头与第三个字母是 K 的词，哪种多，大概差几倍？
- 题二：只许用两张表：空难报道 12 条、车祸 3 条，死亡 0 人与 210 人，哪个说法对？
- 答案：第三个字母是 K 的多，约两到三倍；C 对，两张表量的不是同一个东西。
- 招式：查分母——判断多不多用的是想起来多容易，不是计数。
- 现实：听到「最近特别多」，先问一句：多，是在多少里面多。

#### 第97关｜代表性启发
- 题一：琳达 31 岁、读哲学，A 是银行出纳，B 是出纳且关心社会议题，哪个更可能？
- 题二：收起描述只给人数表：百万人中出纳 3 万、关心四成、环保一半，四说法排序。
- 答案：A 更可能，加「并且」只减不增；排序 D、A、B、C，前三结构定，D 与 A 表定。
- 招式：条件只减不增——每加一个「并且」就再筛一遍，筛子不会变出人。
- 现实：听到完整人物画像，先数里面套了几个条件，再判断可不可能。

#### 第98关｜双系统
- 题一：球拍和球一共 1.1 元，球拍比球贵 1 元，球多少钱？
- 题二：五个场景判停或不停，只许用四个信号：数字、概率、反例、利益。
- 答案：球 0.05 元；一二三五停、四不停，看句中有无可检验的东西。
- 招式：停三秒——把答案代回原题，看两个条件是否同时成立。
- 现实：听到带百分比的报价，先代回原句，看它和另一个条件对不对得上。

#### 第99关｜元认知
- 题一：给长江长度等五个数各报一个九成把握区间，你中了几个？
- 题二：每做一个判断先选五成、七成或九成，每档至少五个，怎样算校准好了？
- 答案：五成档中两到三、七成档三到四、九成档四到五；三档一起对才算校准。
- 招式：记命中率——确定只是感觉，事先写下、事后对账才成刻度。
- 现实：今晚写三条带日期、可判定的预测，各标一档，到期只记中没中。

#### 第100关｜终关·一百关
- 题一：三个局面各报一招：用户规模翻四倍、方案风险很低、项目投半年没起色。
- 三问：三局面各用哪招；只带三招带哪三招；一百关教了什么
- 答案：按局面找不按名字找；带停三秒、查分母、已付出的不算；招式是可复用的形状。
- 招式：先看局面——别背招式名，先看手里有什么，再落到名字。
- 现实：卡住时写一行：我手里是什么，查表补招式名，攒成局面本。
