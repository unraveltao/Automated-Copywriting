# 逻辑闯关写作 · 技能包

**中文名**：逻辑闯关写作
**英文 id**：`logic-levels`

## 这是什么

一份写给 AI 看的操作手册：给它一个关卡号，它按《像玩游戏一样学》的开发文档，写出合格的一关——两题、穷举答案、招式名、现实运用、固定尾句，再压成小红书文档版或知乎回答版。

它不生产观点，只保证不跑偏：加粗配额、可跳读句、禁用词、篇幅、季终关结构，全都写死在规则里。

## 上传

**方式一（推荐）**：把整个 `logic-levels/` 目录压成 zip 上传。多数技能平台接受这种结构：根目录下要有 `SKILL.md`，其余文件按需加载。

**方式二**：平台只收单个 `.md` 时，用同目录下的 `logic-levels-单文件版.md`。它是 `SKILL.md` 加六个参考文件拼接而成，章节已降级，顺序一致。

上传前自查：

- `SKILL.md` 开头的 `---` 块完整，含 `name`、`description`、`whenToUse`。
- 全部文件是 UTF-8，无 BOM。
- 正文里没有本机绝对路径（盘符路径、用户目录）。
- 没有把 `references/` 里的示例当成硬性要求抄进正文。

## 怎么用（触发词）

| 你说 | 它会做 |
|---|---|
| 写第 101 关 / 写下一关 | 先按季制规划下一关，再出母稿与小红书版 |
| 把第 41 关改成小红书 | 800–1000 字文档版 + 封面参数 |
| 批量出小红书素材 | 封面 1080×1440、卡片 5 张、文档版 md + docx，一次跑 100 关 |
| 把第 41 关改成知乎 | 16 字内标题 + 回答体 + 标签 + 可挂问题 |
| 体检第 41 关 | 先跑格式体检，再跑逻辑体检，逐条列硬伤与改法 |
| 这一关写了什么 | 查 `06` 对应条目，给两问、答案口径、招式与落点 |
| 规划第十一季 | 查撞题、排难度曲线、给选题表 |

## 配套脚本（在项目 `04-工具/` 里，不在技能包内）

| 脚本 | 作用 |
|---|---|
| `make_covers_wx.py` | 公众号 / 知乎封面 1280×792，数据直接读文章文件名 |
| `make_xhs_covers.py` | 100 关小红书封面 1080×1440，数据直接读文章文件名 |
| `make_xhs_cards.py` | 5 张卡片一套（封面/题目/答案/为什么/招式），自动或手写 |
| `mk_xhs_note.py` | 公众号母稿 → 小红书文档版 md → docx（草稿，800–1000 字） |
| `md2docx.py` | md → docx，108×192mm / 11pt / 1.9 行距 |
| `series.py` / `new_series.py` | 合集路径与元数据 / 新建合集骨架 |

技能包不打包这些脚本：平台能否执行 Python + Pillow 无法确认，所以只把**参数与命令**写进 `04`。

路径按合集走（`01-内容/<合集>/`、`02-视觉/<合集>/`、`06-存档/<合集>/`），所有脚本都认 `--合集 X`，默认 `逻辑闯关`。

## 它默认不做什么

- 不替你做平台登录、上传、发布。
- 不编造题目来源，不虚构数据。
- 不把公众号长文原样转成小红书文档（平台规则要求重写）。
- 不改已发布关卡的正文（错别字除外）。
