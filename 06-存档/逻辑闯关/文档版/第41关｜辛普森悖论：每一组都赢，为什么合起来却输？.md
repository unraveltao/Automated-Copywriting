# 第41关｜辛普森悖论：每一组都赢，为什么合起来却输？

> 本关不需要前置知识。只要会看百分比。

数据一般不说谎，但把数据摆在一起的方式，能说出任何结论。这一关的现象最邪门——它不是算错，是真的。

## 题目

有两种手术方法，治同一种病（肾结石）。医院做了统计，各治了 350 个病人。

病人分两类：小石头（好治）和大石头（难治）。

小石头：方法 A 81 / 87 = 93%，方法 B 234 / 270 = 87%

大石头：方法 A 192 / 263 = 73%，方法 B 55 / 80 = 69%

合计：方法 A 273 / 350 = 78%，方法 B 289 / 350 = 83%

看这张表，回答两个问题：

1. 小石头病人，该用哪种方法？

2. 大石头病人，该用哪种方法？

3. 如果只问"总体上哪种方法更好"，答案是什么？

## 答案

**前两个问题，答案都是 A。第三个问题，答案是 B。**

去看 A 和 B 各自治的病人构成。

取决于你要问什么。两个都可以是真的。

这就是辛普森悖论的全部机制：一个没被控制的变量（病情严重程度），把两组的"平均分"搅乱了。

## 这招叫什么

**分层与合并**

看到"总体更高/更低"，先问一句：这两组的构成一样吗？

> 一句话：不一样，就不能直接比。要么分层比，要么把构成调成一样（这叫标准化）。

看到总体更高，先问两组构成是否一样。

## 现实运用

先破除一个误解：不是所有"合计"都有问题。只有当两组的构成差异很大，而且那个构成本身影响结果时，合计才会骗人。所以第一步是先看构成。

能用的是这个动作：**看到一个"总体"数字，先找它的分母是怎么构成的。**

- 两个团队的人效：A 团队人均产出 80 万，B 团队 120 万。所以 B 更强？先看构成：A 团队一半是新人，B 团队全是三年以上的老人。人均产出比的不是管理，是团队年龄结构。

- 两家公司的转化率：我们转化率 3%，对手 8%。是不是我们产品差？先看流量来源：我们 70% 是信息流买来的泛流量，对手 70% 是搜索来的精准流量。分母不一样，转化率不能直接比。
