# dsh 命令面板速查

> 用途：搞清楚面板里那 8 个条目各管什么，尤其是 Permission。
> 一句话：**上半部分是动作（做完就完），下半部分 Commands 是会话设置（改完一直生效）。**
> 界面外面怎么用（换形态启动、装插件、改配置）见 `dsh-命令行与配置.md`。

---

## 一、面板结构

```
File / Goal / Plan / Feedback        ← 动作：执行一次
Commands
  Compact / Permission / Model / Export   ← 设置：改的是这个会话的行为
```

这两组最容易混。区别在于：动作是"做一件事"，设置是"改一个规则"。点了 Goal 不等于开了 Plan，点了 Model 也不会让 Permission 变。

---

## 二、8 个条目

| 条目 | 原文 | 作用 | 什么时候用 |
|---|---|---|---|
| File | File | 文件操作子菜单 | 需要显式指定它读哪个文件，而不是让它自己找 |
| Goal | Set or view the goal for a long-running task | 给长任务定一个目标，之后每次行动都对照它检查 | 跨多个文件、要跑很久的任务，防止跑偏 |
| Plan | Enter or leave plan mode | 计划模式：先给方案，不动手；你确认后才执行 | 重构、批量改动、动结构之前 |
| Feedback | Record feedback about this session | 记录对本次会话的反馈 | 它答得好或不好，想留下记录 |
| Compact | Compact older conversation history | 把早期对话压成摘要，腾出上下文窗口 | 会话变长变慢，或开始忘事 |
| Permission | Switch the permission preset (sandbox mode + approval policy) | 切换权限预设：沙箱 + 审批 | 见第三节 |
| Model | Select the model for this conversation | 选这个会话用哪个模型 | 简单任务换便宜的，难任务换强的 |
| Export | Download this session log as a ZIP archive | 把整个会话导出成 ZIP | 存档、复盘、发给别人看 |

### 两个容易误解的

**Compact 不是"清空对话"。** 它把早期内容压成摘要保留下来，所以你还记得结论，只是细节被压缩了。开新会话才是真的清空。会话变慢、开始重复问已经答过的事，通常就是上下文塞满了，这时候按 Compact 比开新会话划算。

**Model 和 Permission 是两件不相干的事。** 它频繁停下来问你，是审批策略在起作用，不是模型笨；想让它少打断就调 Permission，想让它更聪明才调 Model。把这两件事混在一起，会得出"换个贵模型它就不啰嗦了"这种错误结论。

---

## 三、Permission 详解

Permission 不是一个"安全等级滑杆"，是**两个独立维度**：

- **沙箱模式**：它能不能碰到真实环境。开 = 改动被关在隔离环境里，搞砸了不波及真实文件；关 = 改动直接落盘。
- **审批策略**：它动手前问不问你。严 = 每步停下来等你确认；松 = 自己一路做完，只在遇到危险操作时才停。

两个维度交叉，四种体验：

| | 沙箱开 | 沙箱关 |
|---|---|---|
| **审批严** | **最安全**<br>读代码、跑测试，碰不到外面 | **较危险**<br>直接改真东西，靠你每次点头兜底 |
| **审批松** | **较安全**<br>批量干活，伤害被关在沙箱里 | **最危险**<br>只在你完全信任时开 |

**沙箱是主导因素**，不是审批。沙箱开着，就算审批松，最坏结果也只是白干一场；沙箱关着，就算每步都问你，你点错一次就是真的错了。

### 判断口诀

只有一句：**先问"搞砸了能不能撤销"。**

- **能撤销**（改文案、重命名、生成图片）→ 审批调松，让它一次做完。沙箱保持开。
- **不能撤销**（删文件、改配置、动数据库、跑支付）→ 审批调严，宁可多停几次。沙箱也保持开。

### 最该警惕的组合

**沙箱关 + 审批松。** 等于把真实文件交出去，中间还不设卡。只适合一种情况：任务完全确定、你已经验证过一遍、而且有备份。

### 一个常见误区

很多人以为"关掉沙箱 = 更自由 = 更好用"，方向反了。**关沙箱不会让它更能干，只是让它闯祸时能闯到真东西上。** 真正让它更能干的是 Model，或者给它更清楚的任务描述。

## 四、场景速查

| 我的感受 | 该调什么 |
|---|---|
| 它老停下来问我，很烦 | Permission → 审批调松（沙箱保持开） |
| 它改完我不敢信 | Permission → 沙箱开 + 审批严 |
| 它忘了前面说过的话 | Compact |
| 它答得太浅、想得不深 | Model 换强的 |
| 它跑着跑着偏题了 | Goal 定目标，或 Plan 先让它出方案 |
| 它一上来就乱改 | Plan 模式，先看方案再放行 |
| 想留个记录复盘 | Export |
| 觉得它这次答得好 / 很差 | Feedback |

---

## 五、三条提醒

1. **这些设置只对当前会话生效**，不影响你别的会话。不确定就先选保守的，被卡住了再临时放宽。
2. **不确定的时候，选"沙箱开 + 审批严"。** 它最多让你多点几次确认，不会让你损失东西。
3. **别为了省事把沙箱关掉。** 审批可以松，沙箱尽量别关——这是唯一一个"关了就回不去"的开关。
